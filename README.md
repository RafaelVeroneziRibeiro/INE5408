# INE5408 - Data Structures 

[![Language](https://img.shields.io/badge/Language-C++-blue.svg)](https://isocpp.org/)
[![Status](https://img.shields.io/badge/Status-Completed-success)](#)

This repository contains the practical projects developed for the **INE5408 - Data Structures** course. The projects focus on implementing and applying foundational data structures—such as Stacks, Queues, and Tries—to solve real-world computational problems in **C++**.

##  Repository Structure

The repository is organized by project. Each folder contains the source code (`main.cpp`), the input files, and a detailed PDF report explaining the implementations.

*    ### Project 1: Robot Cleaner
      **Data Structures:** Stacks (LIFO) and Queues (FIFO).
      **Application:** Validating XML files and calculating the cleanable area of a robot vacuum using Connected Components (4-neighborhood).
*    ### Project 2: Trie Dictionary
      **Data Structures:** Trie (Prefix Tree / Digital Tree).
      **Application:** Efficiently indexing large dictionary files in secondary memory and identifying word prefixes.

##  Technologies Used
*   `C++` (Standard Template Library - STL)
*   Concepts: Object-Oriented Programming, Memory Management, File I/O, Graph Traversal (BFS), and Tree Traversal.
